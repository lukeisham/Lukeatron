Two scores, two questions

Popularity
How many reference sources list this device?
AI confidence
How sure is the AI that this entry is right?

Both are guides, not grades. Neither one tells you how good a device is.

Popularity, from 0 to 100

The more sources that name a device, the higher its score.

  1. Take the sources listed below: four lists of devices and eight reference pages.
  2. For each device, count the sources that name it. Its name or any other name it goes by will do. A source counts once, however often it repeats the name.
  3. Turn that count into a score. The device named by the most sources gets 100. A device named by none gets 0.

The scale is not a straight line. Most devices appear in only one or two sources, and a straight line would squash them all near zero. So the first few sources count for more than the last few.

What the score does not tell you

  • It shows how widely a device is listed. It does not show how often people use it, or how useful it is.
  • Six more sources were chosen but could not be read: some block automatic visits, one is behind a paywall, and some are gone. They are not counted.
  • The three fallacy sources count only for fallacies.
  • Wikipedia counts as one source here, to find which devices are named. It is never used to check a definition.

AI confidence: high, medium or low

The rating says how sure the AI is that a device’s definition, example and place in the three lists are all right, taken together. It is set once, when the data is prepared, and does not change as you browse.

Each device is given three yes-or-no tests.

TestIt passes when…
1. Definition The device has one settled meaning, and either two or more of the sources below name it, or a published book or paper (one that is not already one of the sources) gives the same meaning. Commercial and hobby sites do not count.
2. Example It has an example, and someone who did not know the device’s name could still spot it from that example. For a fallacy, the example must plainly make the mistake.
3. Placement Its place in the Form, Function and Category lists follows the written rules for those lists directly, without a hard choice between close headings.

Then count the passes.

PassesRatingWhat it means
3HighSafe to teach from as it stands
2MediumWorth a check before you rely on it
0 or 1LowA draft; check it before use

Two extra rules apply. A device that fails Test 1 can never be High, because nothing outside the AI backs its definition. A Flipside is rated on its own and can reach Medium at most, because its label appears in no source.

What the rating does not tell you

  • It is the AI’s own judgement, not a measured fact.
  • Nobody has yet checked the example and placement tests (Tests 2 and 3).
  • Many definitions passed Test 1 because Silva Rhetoricae cites an older book for them. The AI did not read those books, so the check is second-hand.
