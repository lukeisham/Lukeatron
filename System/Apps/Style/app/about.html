Style is an offline reference to elements, kept for teaching preparation. Each group in the app is a different way in. This page explains what each group shows and how the scores and text fields are meant to be read; sections written for link labels follow the first four.

Runs on
Local only: a Python 3 standard-library server at 127.0.0.1, port 8806.
Data
SQLite file style.db, read-only for browsing. The only writable data is the labels, their tables and the elements filed under them.
Screen
Plain HTML, CSS and JavaScript; no framework, no build step. Sorting, search and filtering run in the browser.

Groups

Each button above the list opens a group. Pressing the open group again clears it, and search then looks through Templates, Brainstorming, Research and Topical together.

GroupShows
AlphabeticalEvery element A to Z.
Templates, Brainstorming, Research, TopicalFour independent hierarchies. An element may sit under any number of headings in each, and in none.
Labelsyour own arrangement: labels you create, nest and order, with elements filed under them (§2).
GridEvery thumbnail as a tile, each opening its element. Filter by Issues or Fixes (§5).
IndexEvery real quote, by first line, source or date.
CompareAn element beside its counterpart, in a table.

Labels is the only group the app lets you change. Search, the Display options, Copy and Print serve every group.

Elements, types and labels

Three kinds of item, from smallest to widest.

  • Element: the smallest item. It has a name, a definition, an example, a real quote, thumbnails and an AI-confidence rating.
  • Type: a record with the same fields as an element, tagged Type. It is listed in Alphabetical beside the elements. In Templates, Brainstorming, Research and Topical it works as a heading that holds elements and other types.
  • Label: only an organiser, with a name and an optional explanation. Labels are yours to arrange; elements and types are filed under them, but a label is not a type.

Labels

A label has a name, an optional explanation, and any number of sub-labels, up to five levels deep. An element may be filed under as many labels as fit, at any level.

Adding and arranging

  • Add label takes a name, an optional explanation and, if wanted, a parent to go under. Leave the parent empty for the top level.
  • Add element files an element under a label; each label also has its own Add element button.
  • Drag a label onto the middle of another to put it inside; onto the top or bottom quarter to put it before or after. Drag an element onto a label to file it there, or onto another element to place it.
  • Click a label to open or close it; double-click to show it alone.
  • Edit mode, in the Display menu, switches all editing off for safe reading.

Links

Add link makes a label that shows its name as a link to a new, empty section at the end of this page, for writing in. A link has no explanation and holds nothing.

Tables

Each label can hold up to five tables, with a set number of columns and rows and optional column and row headings. Paste from a spreadsheet to fill one. Copy writes a table as comma-separated lines.

Marking text

In names, explanations, examples and table cells, *word* makes italics and _word_ makes bold.

AI confidence

A stored value, set when an element is written into the database and never recomputed in the browser.

A label (high, medium or low) for how confident the AI is that an element’s definition, example and classification are accurate together. It defaults to low, so an unrated element never reads as trusted.

LabelReading
HighSafe to teach from as it stands
MediumCheck before relying on it
LowDraft; check before use

The badge shows on screen only; Print and Copy leave it out.

Examples and real quotes

An element can carry two kinds of example, shown in a fixed order: the AI example first, then the real quote.

AI example

A constructed example written by the AI to illustrate the definition. It is never credited to anyone, so it cannot pass as a real quote.

Real quote

Words a named person, or a long-standing common saying, actually used, credited in a closing bracket. The Index lists every real quote, and sorts by date when one is recorded. A quote with no known date comes last.

Thumbnails and the Grid

Style is for diagnosing and solving graphic design issues. An element can carry small images, kept as light PNG files so the whole grid loads quickly.

Issue and fix

Each image is marked as an issue, which shows what the problem looks like, or a fix, which shows the same problem solved. An issue badge is filled and a fix badge outlined.

The Grid

  • Every thumbnail appears as a tile with its role, its element’s name and its caption. Click a tile to open its element on its own.
  • The buttons above the grid show all images, only issues, or only fixes. Search matches an element’s name or a caption.
  • Copy writes one line per thumbnail; Print lays the tiles out on the page.

Under an element

An element’s own thumbnails sit under its examples. Show images, in the Display menu, turns them off in lists; they still show when the row is opened.
