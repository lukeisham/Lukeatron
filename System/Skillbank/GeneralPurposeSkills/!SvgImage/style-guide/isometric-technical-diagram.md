# Isometric technical diagram style
**Tags:** technical | data-viz
**Anti-patterns / Avoid:** no perspective convergence toward a vanishing point; no gradients on faces (flat tone per face only); no more than three tones per material; no drop shadows implying a light source inconsistent with the face shading; no isometric-tilted text (labels stay upright and flat).
**Visual DNA:** Clean 30° isometric projection of a mechanism, object, or room — flat-shaded faces (light/medium/dark of the same hue), no perspective convergence, thin consistent outlines, minimal upright labels — the technical "how it fits together" look.
**Typical subject / composition:** Choose this style to show 3D assembly and spatial relationship — mechanisms, exploded parts, room/furniture layouts, network or system-topology boxes-and-connectors rendered as solids, single objects cut away to show internal fit. Composition is usually one hero object or a small assembly centred on the canvas, sometimes with 2-4 parts exploded along their iso axis with thin leader lines. Not for measurable/dimensioned engineering drawings (use blueprint-schematic) and not for photoreal environmental cutaways (use national-geographic-cutaway).
**Standard layers (z-order, bottom → top):**
- `<g id="iso-grid">` — faint construction grid, may be left invisible/hidden
- `<g id="base-plane">` — ground/floor plane in iso, doubles as the Necker-cube fix (anchors which face reads as "up")
- `<g id="object-faces">` — sub-group per solid, painter's-algorithm ordered (see below), each face flat-shaded
- `<g id="object-outlines">` — thin uniform outline over the shaded faces
- `<g id="contact-shadows">` — soft flat ellipse/blob under each solid where it meets the base plane, reinforcing depth
- `<g id="labels">` / `<g id="dimensions">` — upright, non-rotated text and leader lines
**Distinctive SVG techniques:**
- True isometric axes: the two horizontal axes sit at ±30° from horizontal, the vertical axis stays vertical. A unit step along a horizontal axis moves `0.866` (cos 30°) across and `0.5` (sin 30°) down/up; a unit step along the vertical axis moves straight down/up with no horizontal component.
- Unit-cube point list (copy directly), cube edge = 1 unit, apex at origin `(0,0)`: top vertex `T=(0,0)`; the top face's other three corners `TL=(-0.866,0.5)`, `TR=(0.866,0.5)`, `TB=(0,1.0)`; drop each down by the cube height `h` along the vertical axis (`+h` to `y`) to get the matching bottom-face points `T'=(0,h)`, `TL'=(-0.866,0.5+h)`, `TR'=(0.866,0.5+h)`, `TB'=(0,1.0+h)`. The top face is `T,TL,TB,TR`; the left face is `T,TL,TL',T'`; the right face is `T,TR,TR',T'`.
- Two build approaches: (1) **plot points directly** from the 0.866:0.5 ratio above and emit `<path>`/`<polygon>` — preferred, fully predictable at any zoom; (2) **transform route** — draw each face as a flat 2D shape then apply `skewY(±30) scale(0.866,1)` (or the equivalent `matrix(0.866,0.5,-0.866,0.5,0,0)` for one axis) per face group. The transform route distorts `stroke-width` non-uniformly across skewed axes — set `vector-effect="non-scaling-stroke"` on every stroked shape inside a transformed group to keep outlines even.
- Grid module: on a 1080-wide canvas, use a base unit of **60px** (18 columns across); derive the iso step as horizontal `60 × 0.866 ≈ 52px`, vertical `60 × 0.5 = 30px`. Scale the unit up/down per composition but keep the 0.866:0.5 ratio fixed.
- Face-tone formula: pick one base hue `H` and saturation `S` (keep both constant across all three faces — constant hue is what reads the solid as one material). Assign lightness by face: top/up-facing `L = 78%`, one side face `L = 58%` (Δ−20 from top), the other side face `L = 38%` (Δ−20 from the first side). So the triplet is `HSL(H, S, 78%)` / `HSL(H, S, 58%)` / `HSL(H, S, 38%)` — a flat −20% lightness step per face, same H and S throughout.
- Painter's algorithm (actual sort rule): project every solid's centroid onto the view direction `(x + y·0.866 + z·0.5)` in iso space and sort back-to-front (largest projected depth drawn first, smallest/nearest last), so nearer solids and faces overpaint farther ones — draw far to near, never by arbitrary layer name alone.
- Necker-cube fix: true isometric has no depth cue on its own and can read as concave/convex ambiguously. Always include at least one of: a ground plane the object sits on, a contact shadow beneath each solid, or a foreground edge/solid that occludes part of another — pick whichever the composition supports, but never leave a floating solid with none of the three.
- Optional exploded/offset: separate a part along its iso axis with a thin leader line to show assembly order.
**Palette:** one hue family per object with three lightness steps per the formula above, plus a neutral ground and dark outline; e.g. `#bcd6ee` (L≈78%) / `#7ba3d1` (L≈58%) / `#4f79a8` (L≈38%) for a blue object at `H≈212°, S≈45%`.
**Typography:** small, technical sans-serif (`Helvetica, Arial, sans-serif`) for labels, always upright/unskewed regardless of the face it annotates; a monospace face if measurements are shown.
