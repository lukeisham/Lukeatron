## Boss decisions (Opus) — settle spec gaps centrally so all builds agree
- **AD-BOSS-1 · ID format.** Every entity id is `<prefix>-<8 lowercase hex>`, generated once
  on creation and persisted; never regenerated, never derived from content. Prefixes:
  `node- topic- bi- les- ua- mini- crib- res- ri- crit- mtx- stu-`. Generated by one shared
  JS function `newId(prefix)` in `app/js/ids.js` using `crypto.getRandomValues` (no dependency).
  Images keep the datamodel spec's own 32-hex `Image.id` and `img-NNNN.ext` filename — unchanged.
- **AD-BOSS-2 · Dates.** `meta.dateCreated` / `meta.dateModified` are ISO-8601 UTC strings
  (`new Date().toISOString()`), auto-managed by `local-store` on every write. Any user-facing
  date a teacher types (lesson scheduling) is a plain `YYYY-MM-DD` string, stored verbatim.
- **AD-BOSS-3 · Image deletion (INV-DM-17 cascade).** Deleting an image whose id is still
  referenced by any ImageRef is REFUSED, not cascaded; the UI names the parts holding the
  reference. Fails closed, matching the house invariant discipline.
