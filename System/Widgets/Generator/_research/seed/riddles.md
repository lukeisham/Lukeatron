## Collection Summary

This document contains 78 riddles from public-domain or freely-attested traditional sources across multiple cultures and time periods. Each riddle includes:
- Riddle text (concise, typically 1–3 sentences)
- Canonical answer
- Variant answers for fuzzy matching
- One clue that nudges without revealing
- Difficulty rating (easy/medium/hard)
- Cultural tradition/origin
- Source attribution with URL
- Public-domain / licence note

The widget displays one riddle; on request reveals the clue; the user types an answer; the widget checks it (see *Answer-Checking Guidance* below).

### Anglo-Saxon Exeter Book (c. 8th–10th century)

#### Riddle EX-001
**Text:** A moth ate words. When I heard of that wonder, it seemed to me a strange thing—that the worm should swallow the riddle of certain men, a thief in the darkness, and their glorious pronouncements.

**Answer:** Bookworm (or book-eating moth)

**Accepted variants:** [bookworm, book worm, moth, book-moth, worm, insect]

**Clue:** This creature loves knowledge more than you do—it consumes words.

**Difficulty:** medium

**Tradition/Origin:** Anglo-Saxon Exeter Book, Riddle 47

**Source:** [Anglo-Saxon Riddles of the Exeter Book/Annotated/42 - Wikisource](https://en.wikisource.org/wiki/Anglo-Saxon_Riddles_of_the_Exeter_Book/Annotated/42); [The riddles of the Exeter book - Internet Archive](https://archive.org/stream/riddlesofexeterbook00tuppuoft/riddlesofexeterbook00tuppuoft_djvu.txt)

**Licence/Public-Domain Note:** Public domain; translation by Paull Franklin Baum (1963)

## Answer-Checking Guidance

### Normalisation Rules

The widget's fuzzy answer-matching logic should implement the following normalisation steps before comparing the user's answer to accepted variants:

1. **Case insensitivity:** Convert all input to lowercase.  
   - Input: "FIRE" → "fire"

2. **Whitespace normalization:** Strip leading/trailing whitespace; collapse internal multiple spaces to single spaces.  
   - Input: "  fire   " → "fire"

3. **Article removal:** Strip leading "a", "an", "the" (case-insensitive).  
   - Input: "the fire" → "fire"  
   - Input: "a needle" → "needle"

4. **Pluralization:** Strip trailing 's' if present, OR check both singular and plural forms.  
   - Input: "candles" → match against "candle"  
   - Input: "fires" → match against "fire"

5. **Common abbreviations and variants:**  
   - "n't" → normalize to full form if needed (e.g., "can't" → "cannot")  
   - Accents and diacritics: normalize or strip (e.g., "café" → "cafe")

### Fuzzy Tolerance (Edit Distance)

Implement a **Levenshtein distance** threshold to allow minor typos:

| Canonical Answer Length | Max Edit Distance | Rationale |
|---|---|---|
| 1–3 chars | 0 | No tolerance (e.g., "fire" → must be exact) |
| 4–6 chars | 1 | Allow one character change (e.g., "candle" → "canble") |
| 7–12 chars | 2 | Allow two character changes (e.g., "silkworm" → "silkwrom") |
| 13+ chars | 3 | Allow three character changes |

### Variant Matching Strategy

For each riddle, the `accepted-answer variants` array lists common near-misses, synonyms, and alternate spellings that should be treated as correct. Match these **exactly** (after normalisation) without fuzzy tolerance:

| Riddle | Canonical | Variants (after normalisation) | Logic |
|---|---|---|---|
| EX-001 (Bookworm) | "bookworm" | ["bookworm", "book worm", "moth", "book-moth", "worm", "insect"] | Match any variant exactly; also allow "book" + "worm" as separate words normalized to "bookworm" |
| EN-002 (Egg) | "egg" | ["egg", "chicken egg", "goose egg"] | Match "egg" or "chicken egg" (normalised) |
| FO-012 (Human/Sphinx) | "human" | ["human", "man", "person", "mankind"] | Accept any of these synonyms equally |
| JW-002 (Childbirth) | "childbirth" | ["childbirth", "woman", "pregnancy", "nursing"] | Accept these related concepts (case-insensitive) |

### Edge Cases & Special Handling

1. **Empty input:** Treat as **INCORRECT**.
2. **Numbers vs. words:** "R" (the letter) should match "letter R" or "R" variant after normalisation.
3. **Hyphenated vs. spaced variants:** Normalize both to canonical form (e.g., "book-worm" and "book worm" both → "bookworm").
4. **Variant not in list but semantically close:** Do NOT auto-correct outside the `accepted-answer variants` list. Fuzzy tolerance is for typos only, not meaning.
5. **Non-English script or transliterations:** For riddles with non-English answers (e.g., NO-001 "Skinfaxi"), accept the primary transliteration and common alternate spellings listed in variants.

def check_answer(user_input, canonical, variants):
    """
    Check if user_input matches canonical or any variant.
    
    Args:
        user_input: Raw string from user
        canonical: The canonical answer (e.g., "fire")
        variants: List of accepted variant forms
    
    Returns:
        Boolean (True if correct, False otherwise)
    """
    # Step 1: Normalise user input
    normalized = normalise(user_input)
    
    # Step 2: Check exact match with canonical (normalised)
    if normalized == normalise(canonical):
        return True
    
    # Step 3: Check exact match with any variant (normalised)
    for variant in variants:
        if normalized == normalise(variant):
            return True
    
    # Step 4: Check fuzzy match (edit distance) against canonical only
    canonical_norm = normalise(canonical)
    if levenshtein_distance(normalized, canonical_norm) <= edit_distance_threshold(len(canonical_norm)):
        return True
    
    return False
