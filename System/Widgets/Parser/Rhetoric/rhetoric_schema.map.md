    │   ├── Etymological Fallacy: Original meaning as "true" / Enriching with visual history

    │   ├── Begging the Question: Visual assumes conclusion / Establishing visual axioms
    │   ├── Complex Question: Image with hidden premise / Directing toward core issue
    │   ├── False Dilemma: Only two visual options shown / Forcing decision when urgent
    │   ├── Special Pleading: Exception without reason / Recognizing unique circumstances
    │   ├── No True Scotsman: Redefining to exclude flaws / Defining ideal visual standards
    │   ├── Moving the Goalposts: New evidence demanded / Increasing standards as refined
    │   ├── Burden of Proof: Can't disprove so true / Encouraging open-mindedness
    │   ├── Loaded Question: Visual forcing guilty answer / Taking stance on hard issue
    │   ├── False Cause: Implying causation without proof / Identifying potential correlations
    │   ├── Post Hoc: After this, therefore because / Noticing visual sequences
    │   ├── Cum Hoc: Correlation shown as causation / Using trends tentatively
    │   ├── Slippery Slope: One step leads to disaster / Precautionary visual principle
    │   └── Circular Reasoning: Image proves itself / Self-reinforcing visual system
    ├── STATISTICAL & GENERALIZATION FALLACIES
    │   ├── Hasty Generalization: Tiny visual sample / Rapid visual heuristics
    │   ├── Sweeping Generalization: General rule to exception / Policy consistency
    │   ├── Anecdotal Evidence: Single image vs. data / Humanizing data points
    │   ├── Texas Sharpshooter: Cherry-picked visuals / Finding patterns for ideas
    │   ├── Gambler's Fallacy: Past affects future odds / Recognizing system reset
    │   ├── Survivorship Bias: Only showing winners / Studying success stories
    │   ├── Appeal to Popularity: Many like it so right / Social proof for trust
    │   ├── Appeal to Tradition: Always done this way / Preserving visual wisdom
    │   ├── Appeal to Nature: Natural shown as better / Bio-aligned solutions
    │   └── Middle Ground: Truth between extremes / Negotiating visual compromise
    └── `FORMAL FALLACIES (DEDUCTIVE)`
        ├── Affirming the Consequent: If P then Q; Q therefore P / Reverse-engineering theories
        ├── Denying the Antecedent: If P then Q; Not P therefore Not Q / Missing necessary condition
        ├── Affirming a Disjunct: A or B; A therefore not B / Mutual exclusivity
        ├── Denying a Conjunct: Not both; Not A therefore B / Forced choice
        ├── Fallacy Fallacy: Bad image so claim false / Insisting on rigor
        ├── Personal Incredulity: Don't understand so false / Lacking clear explanation
        ├── Sunken Cost Fallacy: Continuing due to investment / Showing perseverance
        └── Existential Fallacy: Assuming members exist / Exploring theoretical possibilities

    │   ├── Complex Question: Question assumes hidden premise / Directing toward core issue
    │   ├── False Dilemma: Only two choices presented / Forcing decision when urgent
    │   ├── Special Pleading: Exception without reason / Recognizing unique circumstances
    │   ├── No True Scotsman: Changing definition to exclude / Defining ideal standards
    │   ├── Moving the Goalposts: New evidence demanded / Increasing standards as refined
    │   ├── Burden of Proof: Can't disprove so true / Encouraging open-mindedness
    │   ├── Loaded Question: Phrased to force guilty answer / Making figure take stance
    │   ├── False Cause: Assuming cause-effect without proof / Identifying correlations for testing
    │   ├── Post Hoc Ergo Propter Hoc: After this, therefore because / Noticing sequences
    │   ├── Cum Hoc Ergo Propter Hoc: Correlation equals causation / Using trends tentatively
    │   ├── Slippery Slope: One step leads to disaster / Precautionary principle
    │   └── Circular Reasoning: X true because Y; Y because X / Self-reinforcing logical system
    ├── `STATISTICAL & GENERALIZATION FALLACIES`
    │   ├── Hasty Generalization: Tiny sample size / Rapid heuristics for decisions
    │   ├── Sweeping Generalization: General rule to exception / Consistency for fairness
    │   ├── Anecdotal Evidence: Personal story vs. data / Humanizing data points
    │   ├── Texas Sharpshooter: Picking fitting data after / Finding patterns for ideas
    │   ├── Gambler's Fallacy: Past affects future random odds / System due for reset
    │   ├── Survivorship Bias: Focusing on winners only / Studying success for traits
    │   ├── Appeal to Popularity: Many like it so right / Social proof for community
    │   ├── Appeal to Tradition: Always done this way / Preserving cultural wisdom
    │   ├── Appeal to Nature: Natural is always better / Sustainable bio-aligned solutions
    │   └── Middle Ground: Truth between two extremes / Negotiating compromise
    └── `FORMAL FALLACIES (DEDUCTIVE)`
        ├── Affirming the Consequent: If P then Q; Q, therefore P / Reverse-engineering theories
        ├── Denying the Antecedent: If P then Q; Not P, therefore Not Q / Identifying missing condition
        ├── Affirming a Disjunct: A or B; A, therefore not B / Mutual exclusivity in binary
        ├── Denying a Conjunct: Not both A and B; Not A, therefore B / Forced choice with resources
        ├── Fallacy Fallacy: Argued poorly so false / Insisting on debate rigor
        ├── Personal Incredulity: Don't understand so false / Theory lacks explainability
        ├── Sunken Cost Fallacy: Continuing due to past investment / Showing perseverance
        └── Existential Fallacy: Assuming class has members / Exploring theoretical "what if"
