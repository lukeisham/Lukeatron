Stage — structural-kinship colour across focus levels

Same sentence, same clause/phrase/word spans, four focus levels. Colour never changes meaning between levels — only which render-kind is "home" (full intensity) changes. The .v-<level> CSS below is normally generated at build time by assemble.py's generate_focus_css() for whatever parser.levels a cartridge declares — reproduced here, byte-for-byte, for the 4-level case (sentential/clausal/phrasal/lexical) so this page needs no build step.

Demo note: a real widget has exactly one #stage element, so assemble.py generates id-based selectors (#stage.v-sentential, etc.). This page shows all four levels side by side, so each demo below gets its own unique id instead (#demo-sentential, …) carrying the *same rules* the generated selectors would apply — see the "Demo-only adapter CSS" note under the code sample for exactly what changed and why.

Relative clause

A dependent clause that modifies a noun, introduced by a relative pronoun.

See also the independent clause it typically attaches to.

Key characteristics

  • Begins with a relative pronoun ("who," "which," "that").
  • Cannot stand alone as a sentence.

References

  1. Huddleston, Rodney, and Geoffrey K. Pullum. The Cambridge Grammar of the English Language. Cambridge UP, 2002.
