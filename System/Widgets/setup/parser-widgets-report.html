Tier A vs Tier B — the reasoning model

Tier A is hardcoded JavaScript: patterns, taxonomies, and fuzzy-matching rules baked into the single HTML file at build time (per Grammar's three-pass engine — lexical, syntactic, conventions/errors). It runs entirely offline with zero external network requests, which is why Grammar and most clones can function as double-clickable files. Tier B is a live API/agent call, reserved for reasoning that needs world knowledge, live judgment, or content genuinely out of reach of hardcoded rules — trope lookup (Story-tension, Tropes & symbols), source verification (Fact-checking), or advanced language/interpretive analysis (Greek and Hebrew, Biblical symbols). Tier B is disabled by default across the chassis (a visible "Tier B check — off" button reserves the slot) and, wherever it is wired, must degrade gracefully when offline or without an API key. Fact-checking is the one parser where Tier B is not optional but core to the tool's purpose.
